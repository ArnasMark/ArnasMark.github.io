ARNAS MARKIAVIČIUS – CV SVETAINĖ (LD7)

Svetainė pritaikyta VILNIUS TECH Skriptinio programavimo 7 laboratorinio darbo reikalavimams.

Pakeitimai:
- HTML dokumentų kalba nustatyta į lietuvių (lang="lt"), koduotė UTF-8.
- Naršyklės skirtuko pavadinimas: „Mano CV“.
- Įrašyti autoriaus vardas ir pavardė bei puslapio aprašymas.
- Pagrindiniame puslapyje pakeistas vardas, profesijos aprašymas ir tekstas.
- Pakeistas CV paveikslėlis: assets/img/arnas-cv.webp.
- Navigacijos meniu išverstas į lietuvių kalbą.
- „Apie“ skiltis pritaikyta elektros energetikos inžinerijos studento CV tematikai.
- Atnaujintas favicon pagal energetikos tematiką.

KAIP PALEISTI:
1. Išarchyvuokite ZIP failą.
2. VS Code pasirinkite File → Open Folder ir atidarykite išarchyvuotą aplanką.
3. Įdiekite Live Server ir Prettier – Code formatter papildinius.
4. Atidarykite index.html ir pasirinkite „Open with Live Server“.

KAIP ĮKELTI Į GITHUB PAGES:
1. Sukurkite viešą saugyklą pavadinimu JUSU_GITHUB_VARDAS.github.io.
2. Įkelkite VISUS šio aplanko failus ir aplankus (index.html turi būti saugyklos šaknyje).
3. GitHub saugykloje atidarykite Settings → Pages ir, jei reikia, pasirinkite publikavimą iš main šakos ir / (root).
4. Svetainė turėtų būti pasiekiama adresu https://JUSU_GITHUB_VARDAS.github.io/.
